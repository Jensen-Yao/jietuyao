# jietuyao v1 → v2 功能迁移总台账

> 原则：**功能只多不少**。v1（Python 版截图耀）的每一项用户可见能力都在此登记，
> 标注其在 v2 中的状态：✅ 已完成 / 🔜 排期（里程碑） / ➕ 由 STranslate 底座超额替代。

## 三、GIF 录屏 → **M3**

选区录制、暂停/继续、帧率选择、逐帧标注、回放裁剪、鼠标点击特效——整体排期 M3（Windows.Graphics.Capture + 原生 GIF 编码替代 Rust wheel）。

## 四、滚动长截图 → **M4**

滚轮自动连拍、手动截、方向切换、冷却、顶部忽略、哈希拼接——整体排期 M4（C# 感知哈希 + LCS 匹配）。

## 五、剪贴板管理 → **M2**

历史（文本/图片/文件/HTML）、搜索过滤、分组、特殊粘贴变换、Win+V、置顶/计数/上限——整体排期 M2。
